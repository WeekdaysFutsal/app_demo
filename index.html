실제 클럽에서 쓰는 앱과 똑같은 기능을 마음껏 눌러 볼 수 있어요. 여기서 한 일은 이 기기에만 저장되고, 다른 사람이나 실제 클럽에는 전혀 영향이 없어요.

회원 로그인아래 목록의 아무 이름 + 숫자 4자리(처음 입력한 숫자가 비밀번호)가상 회원강시우, 고은찬, 남도현, 류지환, 문태오, 배준서…운영모드오른쪽 위 운영모드 → 비밀번호 0000

추천 순서

  1. 회원으로 로그인 → 홈에서 신청하기, 주차·공당·물당 신청
  2. 운영모드 → 설정 → 시뮬레이션으로 신청접수·드래프트·경기모드 연습 데이터 만들기
  3. 가운데 ⚽ 경기모드에서 타이머·휘슬·골 기록
  4. 운영모드 → 공지 → 🔔 알림 보내기 → 회원 화면 오른쪽 위 🔔에서 확인

휴대폰 알림·카톡 캡처 인식 등 일부 기능은 체험판에서 화면으로만 보여 드려요. 위쪽 체험판 버튼을 누르면 이 안내를 다시 볼 수 있어요.
